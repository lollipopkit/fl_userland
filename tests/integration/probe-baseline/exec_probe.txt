## what cannot be run
a path that does not exist                                 -> ENOENT
a path under a file                                        -> ENOTDIR
a directory                                                -> EACCES
a directory with no execute bit                            -> EACCES
/dev/null                                                  -> EACCES
a fifo with the execute bit                                -> EACCES
a regular file with no execute bit                         -> EACCES
an empty file with the execute bit                         -> ENOEXEC
four bytes of nothing in particular                        -> ENOEXEC
a text file with no #!                                     -> ENOEXEC
a path of 5000 bytes                                       -> ENAMETOOLONG
a component of 300 bytes                                   -> ENAMETOOLONG
a symlink loop                                             -> ELOOP
a dangling symlink                                         -> ENOENT
## ELF files that are not programs
the four magic bytes and nothing else                      -> ENOEXEC
a 64-byte header of zeroes after the magic                 -> ENOEXEC
an x86-64 ELF header                                       -> ran, signal 5
an aarch64 header with no program headers                  -> ENOEXEC
a 32-bit ELF header                                        -> ENOEXEC
the real thing                                             -> ran, exit 0
