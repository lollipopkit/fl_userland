  CLOCK_THREAD_CPUTIME_ID                            -> EINVAL
  clock 99                                           -> EINVAL
  TFD_NONBLOCK|TFD_CLOEXEC                           -> a descriptor
    FD_CLOEXEC set                                   -> true
  a flag that means nothing                          -> EINVAL
## timerfd_settime
  gettime before any arm                             -> 0 disarmed
  settime(10s, no interval)                          -> 0 old disarmed
    gettime after                                    -> 0 armed, at or below what was asked
  settime(20s, interval 5s)                          -> 0 old armed, at or below what was asked
    gettime after                                    -> 0 armed, at or below what was asked, interval kept
  settime(0), disarming                              -> 0 old armed, at or below what was asked, interval kept
    gettime after                                    -> 0 disarmed
  settime(value 0, interval 1s)                      -> 0
    gettime after                                    -> 0 disarmed, interval kept
